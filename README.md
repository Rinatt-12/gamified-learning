# 🎮 Gamified Learning System

Оқу процесін ойын механикалары арқылы ұйымдастыратын интеллектуалды білім беру платформасы.

## 📚 Негізгі пән
Мобильді құрылғыларға арналған Android ОЖ платформасында мобильді қосымшаларды әзірлеу

## 🛠️ Технологиялар
- **Frontend:** React 18 + Vite + TypeScript + Tailwind CSS
- **Backend:** Node.js + Express + TypeScript + Prisma
- **Database:** PostgreSQL (Neon.tech)
- **AI:** Groq API (Llama 3.3 70B)
- **Hosting:** Vercel + Render + Neon

## 👥 Рөлдер
- 🎓 Студент
- 👨‍🏫 Оқытушы
- 👑 Администратор

## 🎯 Негізгі функциялар
- XP, Level, Achievement, Streak
- Leaderboard (жалпы, курс, команда)
- Күнделікті мақсаттар
- Командалық турнирлер
- AI кеңес және қате талдау
- AI тест генерациясы (мұғалім үшін)
- Аналитика және графиктер
- Қазақша/Орысша интерфейс
